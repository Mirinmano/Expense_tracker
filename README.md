## 🚀 Features

- ✅ Track daily, weekly, and monthly expenses
- ➕ Add new expense entries with date, category, and amount
- ✏️ Edit or delete existing expenses
- 📊 View categorized summaries and total spendings
- 📁 Clean, user-friendly interface with responsive design

## ⚙️ Installation

To run the project locally:

### 1. Clone the Repository

```bash
git clone https://github.com/Mirinmano/Expense_tracker.git
cd Expense_tracker
```

### 2. Set Up Backend (Java)

- Use your favorite Java IDE (IntelliJ, Eclipse, VS Code)
- Import the project as a **Maven / Gradle** or **Java project**
- Make sure your database is running and connection settings are correct (update in `application.properties` or `.env`)

### 3. Configure Database

```sql
CREATE DATABASE expense_db;
-- Optionally import schema.sql if available
```

### 4. Run the Application

- Start your Java server (Tomcat/Spring Boot/Jetty)
- Visit `http://localhost:8080` in your browser
